\caption{
Architecture of \TITLE{}. Concurrent inference requests are decomposed
into proof jobs and managed by a global coordinator. The coordinator
tracks request progress and places jobs across prover nodes using
historical execution profiles and reusable setup artifacts. Each node
performs local stage admission using current memory availability and
stage-level resource profiles. Large request and proving artifacts are
accessed through shared storage by reference.
}
\label{fig:architecture}
